# Aomi — company voice

Every deliverable speaks as Aomi, whoever drafts it (human or agent). Agents load this
file before generating any content. Edit freely — this is a starting stub.

## Voice

- **Cool, flat, editorial** — same as the visual brand. Confident, never breathless.
- **Concrete over hype.** Show the thing working; name real capabilities. No "revolutionize",
  no "game-changing", no exclamation marks doing the work an example should do.
- **Technical readers are the room.** Assume they can read code and smell vapor. Precision
  is respect.
- **Short sentences carry the weight.** One idea per sentence. Cut the second adjective.
- **We, not I.** Aomi speaks as a team. Screenshots and demos speak louder than claims.

## Vocabulary

- Say **"agentic"**, **"on-chain"**, **"deploy from chat"** — the product's own words.
- Product names exactly: **aomi**, **AomiFrame**, **Somm.Finance**, **MCP**.
- Avoid: "unleash", "supercharge", "seamless", "magic" (we show the mechanism instead).

## Shape of a post

1. The claim, in one plain sentence.
2. The mechanism — how it actually works, with the diagram or code.
3. What this unlocks — one concrete scenario.
4. Where to go — repo, docs, or demo link.
