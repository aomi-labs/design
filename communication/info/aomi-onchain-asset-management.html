03 Capability breakdown

The capability set, in detail.

Four subsystems, none bolted on — each a property of the runtime, built directly on a full node that forks every chain in ~200ms.

3.1

Execution pipeline

build · simulate · sign · broadcast
Step 01

Build

The agent composes the exact transaction from strategy logic or an intent — batched into a single operation.

intent → exact tx
Step 02

Simulate

Executed against forked, live chain state to prove the real outcome — slippage, balances, risk — before signature.

forked state · ~200ms
Step 03

Sign

Signed by the mandate holder's own wallet under scoped delegation — human-approved or autonomous within caps.

AA bundler · signer's wallet
Step 04

Broadcast

Confirmed onchain with account abstraction and Solana Jito built in — no separate infrastructure to run.

AA + Solana Jito
Best execution that can be evidenced — every fill traceable to a pre-trade simulation and an enforced policy check.
3.2

Control framework

the mandate, enforced
Mandate as configuration

Value caps, allow-listed venues, risk bands, per-wallet rules — defined once, enforced on every action. Human-sync approval or autonomous execution within caps.

value capsallowlistsrisk bands
Kill switch & revocation

Delegation is data, not a handover: halt an agent instantly, revoke a grant instantly. A failed simulation or an out-of-policy proposal stops before signature — by construction.

instant haltinstant revoke
Custody model

Non-custodial by construction. Agents sign through provider-native scoped delegation — Privy & Para compatible — and signing authority never transfers. The runtime's counter reads KEYS HELD: 0, always.

keys never movePrivy · Para
Oversight & reporting

Per-app telemetry on every turn; each action traceable to its originating intent. An audit trail consumable by fund administration, auditors, and allocator due diligence.

full audit trailODD-ready

The invariant: aomi can compose and simulate any transaction, but can only ever propose it. Authority to move value remains with the mandate holder's wallet and policy — including for strategies that run unattended.
