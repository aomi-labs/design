Aomi · agents and user funds
Can an AI agent touch user funds?
Only after five checks.
Check 1 of 5
A fixed shape for every call
Every contract call has a fixed shape.
A wrong transaction cannot even be built.
Check 2 of 5
A test run before every signature
Every transaction runs on a test copy of the chain first.
Signing only happens after the test run passes.
Check 3 of 5
Small permissions, not a master key
The agent gets one small permission for each tool it uses.
There is no single key that can do everything.
Check 4 of 5
Many steps, one plan
A real trade is quote, then approve, then execute.
The agent treats all three as one plan, checked together.
Check 5 of 5
A way to say no
If the test run does not match the plan,
the agent refuses to sign. Nothing moves.
Five checks. Built into Aomi.
Sommelier runs on this today. Keep your strategy layer.
Let the harness do the checking.
