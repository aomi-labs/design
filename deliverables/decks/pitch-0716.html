The product

A hosted runtime
you build on.

You wrap your API as a few tools — a small Rust plugin. Aomi hot-loads it as a live agent. You write tools, not transaction plumbing.

  • Zero setup — simulation, signing & broadcast built in
  • Fast & cheap — execution runs inside the runtime, close to the chain
  • Non-custodial — keys never touch the runtime
