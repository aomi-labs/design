The moat

aomi_run — agents don't click buttons.
They write programs.

  • One request = a whole strategy: loops, pipes, captured results, in a purpose-built DSL that can't escape the sandbox
  • Intermediates never re-enter the model's context → 10–100× cheaper, immune to mid-flight prompt injection
  • Every step passes the same guards, simulation, and signing policy — orchestration scales, safety is invariant
  • DCA, treasury rebalancing, cross-chain yield — one auditable program per intent
