Additional features
Multi-threaded async execution
Agents run concurrent threads server-side, so work continues while you chat — background trading & strategy bots, limit / stop orders, copy-trading a target wallet, scheduled DCA & rebalances, and liquidation guards that fire on their own.
Access control
Provider-native key delegation — Privy · Para compatible — with machine auth solved: an agent signs only under a scoped, revocable policy (value caps, human-sync or autonomous). Keys never leave the user's own wallet.
